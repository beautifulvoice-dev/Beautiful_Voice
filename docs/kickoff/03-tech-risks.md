## 2. 스파이크 제안 (타임박스)

| ID | 질문 | 산출물 | 기간 | 필요 입력 |
|---|---|---|---|---|
| **S1** | 어떤 STT가 한국어 매장 발화(고객명·시술명·시간)에 충분한가? | 벤더별 CER·고유명사 정확도·지연·분당 비용 비교표, ADR | 2~3일 | **카본의 실제 발화 샘플 20~30개**(합성 고객명) + 정답 전사 |
| **S2** | LLM 구조화·의도 분류가 스키마를 지키고 환각 없이 동작하는가? | 프롬프트 v0, 골든 세트 30건, 정확도 측정 스크립트(CI에서 재실행 가능) | 3일 | S1 전사 결과, Q3 정책 |
| **S3** | 기기 업로드 경로 E2E: 녹음 → 업로드 실패 → 재전송 → 중복 없음 | 업로드 API 프로토타입 + 시나리오 테스트 | 2일 | 기기 사양(Q1) 또는 샘플 파일 |
| **S4** | 예약 충돌 규칙을 DB 제약 + 서비스 검사로 표현 가능한가 | 스키마 + 동시성 테스트(병렬 저장 100회) | 1일 | Q6 답변(없으면 1인 수용 가정) |
| **S5** | 파일럿 매장 전화 환경에서 AI 수신이 기술·법적으로 가능한가 | 연동 방식 후보·비용·리드타임·필요 서류 정리 | 2일 (조사) | Q14 매장 번호 유형 |
