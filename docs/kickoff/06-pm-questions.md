# 06. PM(카본) 확인 요청

> 개발팀 → PM. **🔴 = 아키텍처에 영향, 화요일 전 답변 희망** · 🟠 = 스프린트 1 착수 전 · 🟢 = 해당 기능 착수 전.
> 각 질문에 개발팀 기본안을 붙였다. 기본안대로면 "OK"만 주셔도 된다.

## 🔴 화요일 전

**Q1. 마이크 기기는 어떻게 서버로 음성을 보내나요?**
- (a) 기기가 Wi-Fi로 직접 업로드 (b) 스마트폰과 블루투스 연결 후 폰이 업로드 (c) 녹음 후 USB/수동 업로드 (d) 미정
- 영향: (b)면 웹앱만으로는 어려워 **네이티브/하이브리드 앱이 필요**할 수 있음(현재 "네이티브 앱 초기 제외"와 충돌).
- 기본안: 기기 형태와 무관하게 **HTTPS 업로드 API**를 먼저 고정하고, 실물 전까지 샘플 파일 업로드로 개발.

**Q2. 원장님이 웹앱을 주로 어떤 기기로 보나요?** (스마트폰 / 태블릿 / 매장 PC)
- 기본안: 스마트폰 우선 반응형 웹(PWA, 홈 화면 추가).

**Q3. 같은 마이크로 "기록"과 "명령(조회·변경)"을 어떻게 구분하나요?**
- (a) 버튼/모드 분리 (b) 호출어("비서야, …") (c) AI가 자동 분류 후 웹앱에서 확인
- 기본안: (c) + 변경은 항상 승인을 거치므로 오분류 피해 제한. 단, 기기에 버튼 여유가 있으면 (a)가 정확도·비용 면에서 유리.

**Q5. 로그인·사용자 구조**
- 매장당 원장 1명만? 직원 계정이 있나요? 로그인 방식 선호(휴대폰 인증 / 카카오 / 이메일)?
- 기본안: 초기 매장당 원장 1명 + 휴대폰 번호 인증. 구조는 다중 사용자를 허용하게 설계.

**Q9. 개인정보·외부 AI 사용**
- 고객 음성·전사문을 **해외 AI 서비스(STT/LLM)로 보내도 되나요?** (국외 이전 고지·동의 필요 가능)
- 원본 음성 보관 기간? (예: 처리 후 30일 / 무기한)
- 기본안: 국내 리전 저장, 원본 음성 기본 90일 보관 후 삭제(설정 가능), 외부 API 사용은 파일럿 동의서에 포함.

## 🟠 스프린트 1 착수 전

**Q6. 예약 운영 규칙** (P2-03·04·11)
- 동시에 몇 명까지 받나요? (1인 = 동시 1명?) 시술 사이 준비 시간? 영업시간·휴무를 누가 입력?
- 충돌이 있어도 원장이 **강제로 저장**할 수 있어야 하나요?
- 예약 상태 목록: 요청 / 확정 / 취소 / 노쇼 / 완료 — 추가·삭제할 것?
- 기본안: 동시 1명, 준비 시간 메뉴별 설정, 강제 저장 불가(경고 후 시간 변경 유도), 상태는 위 5개.

**Q7. 관리 항목(메뉴) 목록과 소요 시간 데이터가 있나요?** 없으면 첫 화면에서 원장이 직접 입력하는 방식으로 진행.

**Q8. 고객 식별 필수 정보** — 이름만? 이름+전화번호 필수? (동명이인 구분 기준)
- 기본안: 이름 필수, 전화번호 권장(동명이인 시 필수).

**Q11. 음성/채팅으로 지원할 질문 Top 10** (P2-05·07의 "합의한 질문")
- 예: "오늘 예약 뭐 있어?", "김OO 고객 지난번에 뭐 받았지?", "다음 주 화요일 비는 시간?" — 실제 원장님 표현으로 받고 싶음.

**Q12. Phase 1을 카본 님이 직접 개발하시나요?** 그렇다면 같은 저장소·같은 데이터 모델·같은 PR 규칙으로 진행해도 될까요? (Phase 2 음성 기능이 Phase 1 파이프라인을 그대로 씀)

**Q13. 일정·예산**
- 8주의 시작일과 파일럿 매장 수·시점?
- 월 운영 예산 상한(호스팅 + STT/LLM)?
- 개발용 클라우드·AI API 계정은 누구 명의로 만드나요?

**S1 입력 요청:** 실제 매장 상황 발화 샘플 20~30개(가명 고객 사용) + 정답 문장. STT 벤더 비교에 필요.

## 🟢 해당 기능 착수 전

**Q4. 음성 변경 승인 UX** (P2-06) — 손을 못 쓰는 상황에서 승인은 나중에 웹앱에서 탭? 승인 대기 제안은 몇 시간 뒤 만료?

**Q10. 장부 낭독** (P2-08) — 실물 장부 사진 샘플(가림 처리), 한 줄에 어떤 정보? 과거 예약 이력도 입력 대상인가요?

**Q14. Phase 3 전화** — 파일럿 매장 번호 유형(휴대폰/유선/070), 착신전환 가능 여부. 통신·알림톡 연동은 심사 리드타임이 있어 **일찍 조사 시작**하려 함.
