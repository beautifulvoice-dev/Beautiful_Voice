## 3. 2A 완료 기준 (가안 — PM 명세서로 교체)

1. 원장이 스마트폰에서 로그인해 고객을 이름만으로 등록·검색·수정할 수 있다.
2. 캘린더에서 예약을 등록·변경·취소하고, 겹치면 "시간 옮기기 / 강제 저장"을 고른다. 동시 3건째와 영업시간 밖은 강제 저장도 막힌다.
3. 예약 상태 5종과 변경 이력이 저장된다.
4. 고객·기간으로 기록·예약을 찾는다.
5. 다른 매장의 데이터는 어떤 API로도 보이지 않는다.
6. 위 1~5가 자동 테스트로 확인된다(절대 규칙 10).
