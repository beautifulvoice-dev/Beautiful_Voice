## 3. 2A 완료 기준

명세서 수용 기준(2A):
- **AC-2:** 같은 시간에 확정 세션 2건이 있을 때 손으로 세 번째를 넣으면 저장되지 않고 "같은 시간 최대 2건"을 알린다.
- **AC-3:** 세션 뒤 준비 시간 10분 안에 새 예약을 넣으면 겹침으로 판정된다.

개발팀 가안(명세서 나머지 시나리오는 미정 — PM 메모 10번):
1. 원장이 스마트폰·노트북에서 로그인해 고객을 이름만으로 등록·검색·수정하고, 같은 이름이면 확인 요청을 받는다.
2. 캘린더(주·월)에서 세션을 등록·변경·취소하고, 겹치면 "시간 옮기기 / 그대로 저장"을 고른다. 3건째·운영 시간 밖·관리 불가 시간은 그대로 저장도 막힌다.
3. 세션 상태 5종과 변경 이력이 저장되고, 방문 기록이 캘린더와 같다.
4. 지갑 기록을 남기고 잔액·매출이 근거 기록과 맞는다(범위는 §4-1 결정에 따름).
5. 다른 매장의 데이터는 어떤 API로도 보이지 않는다.
6. 위 항목이 자동 테스트로 확인된다(절대 규칙 10).
