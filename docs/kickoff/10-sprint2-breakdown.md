## 4. 같이 지킬 것
1. **DB 마이그레이션은 금요일(11/27)에 한 PR로 먼저**(리더 리뷰). 각자 마이그레이션 파일을 따로 만들지 않고 설계 초안에 필요한 테이블·칸을 적는다.
2. **맞물리는 계약은 금요일 오전에 먼저**: 문자(엔진 ↔ 템플릿 화면 ↔ 5분 전 카드), 지갑 ↔ 고객 상세, 앱 API(ADR-0009 A단계).
3. 서버 PR 체크: `withShop` 안 쿼리 · `shop_id` 조건 · `idempotentWrite` · `version` · 오류 형식 · 도메인 규칙 테스트.
4. 리뷰 시간 하루 두 번, 머지는 사람 승인 + CI `verify` + 미해결 0.
5. 설계(API·데이터)는 각자 직접 쓰고 AI는 검토·구현.
